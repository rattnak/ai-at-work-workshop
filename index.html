03 / GET SET UP

From template to
something useful.

Follow these steps in GitHub Copilot CLI, or watch the demo and return to them later.

01

Get Copilot ready

You’ll need a GitHub account, an active Copilot subscription, and permission to use Copilot CLI. Install the CLI using GitHub’s instructions, then open your terminal and run copilot. If prompted, enter /login.

Verified eligible teachers may qualify for GitHub Education benefits; staff eligibility and approval are not guaranteed. You can still follow along without an account.

02

Choose and download

Download one of the skill files above and read it. Its name must remain exactly SKILL.md. Create a folder for it inside your personal skills directory:

~/.copilot/skills/
  project-handoff/
    SKILL.md

For the weekly update skill, use weekly-update as the folder name instead. To create the project handoff folder, run this in your computer’s terminal (not inside Copilot):

macOS:

mkdir -p ~/.copilot/skills/project-handoff

Windows PowerShell:

New-Item -ItemType Directory -Force -Path "$HOME\.copilot\skills\project-handoff"

For the weekly update skill, replace project-handoff in the command with weekly-update. On macOS, use Finder’s Go → Go to Folder and enter ~/.copilot/skills/; on Windows, enter %USERPROFILE%\.copilot\skills in File Explorer. Move the downloaded file into its matching folder. Don’t replace an existing skill without checking it first.

03

Open and check your skill

Start or restart copilot. Enter /skills to check that your skill appears. If it doesn’t, check the folder and exact filename, restart, and consult GitHub’s skill guide. Then try a prompt below.

04 / USE AI THOUGHTFULLY

Bring your work.
Keep your judgment.

These skills work with notes you provide. Choose information your university permits you to use with the AI tool, and check the draft before sharing it.

APPROVED NOTES → COPILOT + SKILL → YOUR REVIEW

BEFORE YOU START

Keep information safe.

Confirm that GitHub Copilot and the information you intend to use are approved under FHSU policy. Don’t enter confidential, student, personnel, or other sensitive information unless explicitly permitted.

Provide a few notes yourself. The skills do not connect to Outlook or automatically read your work files. They can organize what you supply, but may miss context or make mistakes.

Not sure what’s allowed? Check with FHSU before using real work information. Never paste passwords or access tokens into a prompt.

05 / GIVE IT A TRY

Your turn to
make it useful.

Replace the brackets with notes approved for your AI tool, then review what Copilot creates. No account connection is needed beyond Copilot.

01

Project handoff

YOUR STARTER PROMPT

Use my project-handoff skill to organize these approved notes for [colleague or team]: [project purpose, completed work, remaining tasks, and known deadlines]. Flag missing details and do not invent facts. Do not send or change anything.

Check the result: Confirm the status, owners, deadlines, and any information the next person needs.

02

Weekly update

YOUR STARTER PROMPT

Use my weekly-update skill to draft an update for [audience] from these approved notes: [accomplishments, upcoming work, and any blockers]. Keep it concise, flag missing details, and do not invent facts. Do not send or change anything.

Check the result: Make sure it accurately reflects your work and is appropriate for the intended audience.

✳

You’re always in charge. Check the original notes. AI may miss context or be wrong. Review every draft before sharing it through your normal workflow.
