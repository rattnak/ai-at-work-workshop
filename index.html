01 / THE IDEA

Teach Gemini your
way of working.

A skill is a folder with a SKILL.md file and, optionally, helpful reference files or scripts. Gemini loads it when a request matches its description.

01

Choose a repeatable task

Look for work where you already follow a pattern: summarize, plan, review, explain, or transform.

02

Write the recipe

Describe when the skill applies, the steps Gemini should follow, and what a good result must include.

03

Try, inspect, improve

Use a realistic example. Check the result, tighten the instructions, and keep the judgment that belongs to you.

Gemini app or Gemini CLI?This workshop teaches Gemini CLI, Google’s terminal-based coding and task assistant. The same instruction-writing ideas can inspire Gems in the Gemini app, but the file-based Agent Skills workflow below is for Gemini CLI.

03 / GET STARTED WITH GEMINI CLI

From install to
first useful answer.

Gemini CLI runs in a terminal and works in the folder you choose. Install it, sign in, then add a skill to your workspace or user skills directory.

01

Install and sign in

Follow Gemini CLI’s installation guide. Then open a terminal, move into a project folder, and start Gemini:

cd ~/my-project
gemini

Complete the sign-in flow when prompted. Check Google’s current documentation for account, quota, and authentication options.

02

Download one skill and read it

Choose a skill above and open SKILL.md in a text editor. The frontmatter gives it a name and description; the body gives Gemini the workflow. Treat every downloaded instruction as something to inspect before you use it.

03

Put it where Gemini can find it

For a skill in one project, place the folder under .gemini/skills/. For a skill you want across projects, use your user skills directory. The exact user-level location can vary by platform and Gemini CLI version, so confirm it in the official skills guide.

.gemini/
  skills/
    prompt-coach/
      SKILL.md
04

Invoke it and review the result

Start Gemini in the project, then ask for the skill by name or make a request that matches its description:

/prompt-coach

Help me improve this prompt for a staff update...

Ask Gemini what instructions it used if you are unsure. Never paste confidential information unless your organization has approved that use.

WHAT’S INSIDE?

One clear recipe.
A repeatable result.

▤ SKILL.md
---
name: prompt-coach
description: Improve prompts
  for a clear goal.
---

Ask for the goal and audience.
Identify missing context.
Offer a revised prompt.
Explain what changed.

Start with plain language. A great skill is specific about the task without trying to control every possible conversation.

04 / BUILD YOUR OWN

What do you do
the same way every time?

The best first skill is not the most impressive one. It is the one you will actually use next week. Capture your sequence, your quality bar, and the questions you always ask.

TRY THIS WITH GEMINI

I want to create a Gemini CLI Agent Skill for this repeatable task: [describe the task].

Ask me five questions about the audience, inputs, steps, quality bar, and edge cases. Then draft a SKILL.md with valid frontmatter. Keep the instructions practical, safe, and easy to test. Show me the file and explain how to improve it.
