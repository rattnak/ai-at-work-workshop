01 / THE IDEA

Not another thing to learn.
A better way to start.

Think of a skill as a reusable set of instructions. You bring the task; Copilot uses the skill as a guide for how to help.

01

Choose a task

Pick something familiar: preparing for meetings or catching up on replies.

02

Add a skill

Save a small SKILL.md file to your computer. It tells Copilot what to do and when.

03

Ask, review, refine

Try a prompt, check the result, and adjust the instructions to fit your work.

Good to knowA skill is instructions, not a connection. To use real Outlook information, you’ll also need a university-approved integration and the right permissions. A skill does not run on a schedule by itself.

03 / GET SET UP

From template to
something useful.

Follow these steps in GitHub Copilot CLI, or watch the demo and return to them later.

01

Get Copilot ready

You’ll need a GitHub account, an active Copilot subscription, and permission to use Copilot CLI. Install the CLI using GitHub’s instructions, then open your terminal and run copilot. If prompted, enter /login.

Verified eligible teachers may qualify for GitHub Education benefits; staff eligibility and approval are not guaranteed. You can still follow along without an account.

02

Choose and download

Download one of the skill files above and read it. Its name must remain exactly SKILL.md. Create a folder for it inside your personal skills directory:

~/.copilot/skills/
  daily-meeting-briefing/
    SKILL.md

For the email skill, use email-reply-helper as the folder name instead. To create the meeting skill folder, run this in your computer’s terminal (not inside Copilot):

macOS:

mkdir -p ~/.copilot/skills/daily-meeting-briefing

Windows PowerShell:

New-Item -ItemType Directory -Force -Path "$HOME\.copilot\skills\daily-meeting-briefing"

For the email skill, replace daily-meeting-briefing in the command with email-reply-helper. On macOS, use Finder’s Go → Go to Folder and enter ~/.copilot/skills/; on Windows, enter %USERPROFILE%\.copilot\skills in File Explorer. Move the downloaded file into its matching folder. Don’t replace an existing skill without checking it first.

03

Open and check your skill

Start or restart copilot. Enter /skills to check that your skill appears. If it doesn’t, check the folder and exact filename, restart, and consult GitHub’s skill guide. Next, set up an approved Outlook connection below.

04 / CONNECT TO REAL WORK

Bring your real
Outlook workday in.

An approved Microsoft 365 connection lets Copilot request your real calendar and email information. MCP is the bridge; your skill tells Copilot how to use the information.

OUTLOOK → APPROVED MCP → COPILOT + SKILL

BEFORE YOU CONNECT

Check with FHSU first.

Confirm that the integration, your Copilot account, and the intended use of university data are approved. Availability can depend on Microsoft 365 licensing, tenant configuration, admin consent, and your permissions. GitHub Copilot Pro does not itself grant Outlook access.

Microsoft’s Work IQ MCP integration is one option to ask IT about. It may request broad access to Microsoft 365 data; review the permissions and university policy before connecting. Do not grant access or enter sensitive data unless authorized.

Once approved: In an interactive Copilot CLI session, run these two commands, follow the prompts, and restart Copilot:

/plugin marketplace add microsoft/work-iq
/plugin install workiq@work-iq

Enter /mcp and check for workiq. Your first request may prompt a Microsoft Entra sign-in. Follow your organization’s guidance for authentication and access.

View Microsoft’s setup guide ↗

If access is blocked, contact your administrator; do not bypass the restriction. Never paste passwords or access tokens into a prompt.

05 / GIVE IT A TRY

Your turn to
make it useful.

Once your connection and data use are approved, try these prompts with your real Outlook calendar and email.

01

Meeting briefing

REAL OUTLOOK PROMPT

Use my daily-meeting-briefing skill and the approved Microsoft 365 connection to summarize my meetings today. Suggest relevant documents I can access, cite your sources, and flag anything uncertain. Do not change my calendar or send messages.

Check the result: Compare times with your calendar and open the suggested documents. The skill can only use information its connection can access.

02

Email replies

REAL OUTLOOK PROMPT

Use my email-reply-helper skill and the approved Microsoft 365 connection to find recent messages I may need to reply to. Check available thread history, summarize what each person needs, explain uncertainty, and draft replies for my review. Do not send, create drafts in Outlook, or modify anything.

Check the result: Look at each original thread, confirm whether a reply is still needed, and review the recipient and text before sending in Outlook.

✳

You’re always in charge. Check the original calendar, documents, and email threads. AI may miss context or be wrong. Review every draft and recipient before sending through your normal workflow.
