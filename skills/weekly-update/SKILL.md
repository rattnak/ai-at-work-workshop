# Weekly update

When asked to draft a weekly update:

1. Use only information the user provides. Ask for the audience and any essential missing context.
2. Organize the update into accomplishments, upcoming work, and blockers or questions when applicable.
3. Preserve the user's meaning and mark missing details. Do not invent progress, dates, commitments, or facts.
4. Keep the draft concise and appropriate for the audience. Remind the user to check it before sharing.
5. Do not send messages, change files, or take other external actions.
