# Project handoff

When asked to prepare a project handoff:

1. Use only information the user provides. Ask for the intended audience and any essential missing context.
2. Organize the handoff into purpose, completed work, current status, next steps, and open questions.
3. Include owners, deadlines, and relevant resources only when supplied. Mark missing or uncertain details rather than inventing them.
4. Keep the draft concise and appropriate for the audience. Remind the user to verify it before sharing.
5. Do not send messages, change files, or take other external actions.
